# CHAT_UX_SPEC.md — UX/UI-аудит и ТЗ на доработку экрана чата

> **Для ИИ-агента-исполнителя.** Это спецификация доработки существующего мессенджера (React + TypeScript).
> **Визуальный стиль НЕ меняем**: тёмная тема, скругления, акцентный синий, «стеклянные» карточки, шрифт — всё остаётся.
> Меняем: состав и порядок кнопок, поведение, состояния, доступность, производительность.
> Все цвета, радиусы, тени, отступы берём из **существующих токенов/CSS-переменных проекта**. Новых цветов не вводить.
> Если для значения нет токена — взять ближайший существующий и оставить комментарий `// TODO token`.

---

## 0. Принципы

1. **Минимализм через иерархию.** На экране одновременно не больше 1 primary-действия и 3–4 secondary. Остальное — в меню «⋯».
2. **Одна иконка = один смысл.** Две похожие иконки (сейчас три «искры/звезды» в шапке) недопустимы.
3. **Опасные действия не лежат на поверхности.** Удаление — только через меню с подтверждением/Undo.
4. **Контекстность.** Кнопка/подсказка показывается, когда она уместна (smart-replies, кнопка «Отправить», «Вниз»).
5. **Предсказуемый порядок:** слева направо — от «о ком/чём» к «что делать»; от частого к редкому; деструктивное — в самом конце.
6. **Единый размер хит-зон:** desktop ≥ 36×36 px, touch ≥ 44×44 px (визуальная иконка может быть 20–24 px, увеличиваем область клика через padding).
7. **Каждое состояние описано:** default / hover / focus-visible / active / disabled / loading / error.

## 2. Шапка чата — новая раскладка

### 2.1 Порядок элементов (слева → направо)

```
[← Back (только mobile/узкий)]  [Avatar 40]  [Имя + статус]  [Chat | Gallery]            [🔍 Search] [📞 Call] [🎥 Video] [📌 Pinned·3] [✦ AI] [⋯ More]
```

| # | Элемент | Размер | Действие | Видимость |
|---|---------|--------|----------|-----------|
| 1 | Back | 40 | Назад к списку | только < 768 px |
| 2 | Avatar | 40 | Открыть панель профиля/инфо | всегда; индикатор онлайн — точка 10 px в углу, только если online |
| 3 | Имя (16/600) + статус (13/400, muted) | — | Клик — профиль. Статусы: `online` / `typing…` (акцент) / `last seen 2 minutes ago` | всегда |
| 4 | Сегменты Chat / Gallery (n) | высота 32 | Переключение вида | всегда (на < 1024 px переносятся под шапку) |
| 5 | Search | 36 | Поиск по чату (см. 2.3) | всегда |
| 6 | Call | 36 | Аудиозвонок | всегда |
| 7 | Video | 36 | Видеозвонок | всегда |
| 8 | Pinned (бейдж с числом) | 36 | Список закрепов | только если закрепы есть |
| 9 | AI | 36 | Popover: Summary of chat / Smart reply / Translate / Tone | всегда, **одна иконка** |
| 10 | More ⋯ | 36 | Меню (см. 2.2) | всегда |

**Группировка:** между 4 и 5 — разделитель 16 px. Между 7 и 8 — тонкий вертикальный разделитель (1 px, muted 20%), чтобы отделить «коммуникацию» от «инструментов».

**Адаптив:**
- ≥ 1280: показываем всё.
- 1024–1279: Pinned и AI уходят в «⋯».
- 768–1023: остаются Search, Call, «⋯»; Video → в «⋯».
- < 768: Back, Avatar+имя, Call, «⋯».

### 2.2 Меню «⋯ More» (порядок пунктов)

1. Видео-звонок *(если скрыт)*
2. Информация о контакте / группе
3. Медиа, файлы, ссылки *(открывает Gallery)*
4. Оформление чата (тема, обои, акцент) ← бывшая «палитра»
5. Уведомления: Включить / Отключить звук на… (1 ч, 8 ч, 1 день, навсегда)
6. Закрепить чат
7. Отложенные сообщения
8. Экспорт чата
9. — разделитель —
10. Очистить историю *(красный)*
11. Заблокировать *(красный)*
12. Удалить чат *(красный, подтверждение)*

### 2.3 Поиск по чату

Клик на 🔍 или `Ctrl/⌘+F` → под шапкой выезжает панель 48 px: `[поле поиска] [3 из 12] [↑] [↓] [Фильтр: Все / Фото / Файлы / Ссылки] [✕]`.
`Enter` / `Shift+Enter` — следующий/предыдущий. Совпадения подсвечиваются в ленте, текущее — ярче. `Esc` закрывает.

### 2.4 Баннер закреплённого

Под шапкой, высота 40 px, слева вертикальная цветная полоса (акцент), текст «Pinned message · 1 of 3 — {превью 1 строка}», справа кнопка «список». Клик по баннеру — скролл к сообщению с кратким подсвечиванием (flash 1.2 с), следующий клик — следующий закреп.

## 3. Сообщения — действия и компоненты

### 3.1 Hover-панель действий (desktop)

Появляется при наведении на сообщение (задержка 80 мс, исчезает 150 мс после ухода курсора). Позиция: по вертикали — **над** сообщением, прижата к верхнему краю бабла и выходит за него на ~14 px; по горизонтали — к внешней стороне (для входящих — справа от бабла, для исходящих — слева). Рендерить через портал, чтобы не обрезалась контейнером.

**Порядок кнопок (слева → направо):**

1. ❤️ / 😀 **Реакция** (клик — ♥, «+» — палитра эмодзи)
2. ↩ **Reply**
3. ➡ **Forward**
4. 📌 **Pin / Unpin**
5. ⋯ **More** → Copy, Edit *(только свои, ≤ 48 ч)*, Select, Report, Info (кто прочитал), **Delete** *(красный, последний)*

Стиль: контейнер-«пилюля» высотой 36 px, фон `surface-elevated`, граница 1 px, лёгкая тень; иконки 18 px; подписи (Reply, Forward) **убрать из панели** — показывать тултипом (экономит ширину и убирает обрезание).

**Mobile:** долгий тап → bottom-sheet с реакциями сверху (ряд из 6 эмодзи) и вертикальным списком действий. Свайп вправо по сообщению = Reply (с хаптиком и иконкой-стрелкой, порог 56 px).

**Правый клик (desktop)** открывает то же меню, что и «⋯».

### 3.2 Время и статусы

- Время: 12 px, muted, внутри бабла справа снизу. У стикера/медиа/карточек без бабла — полупрозрачная пилюля (фон `rgba(0,0,0,.45)`, blur) в правом нижнем углу.
- Показывать «изменено» рядом со временем у отредактированных.
- Статусы исходящих: `⏱` в очереди → `✓` → `✓✓` серые → `✓✓` синие. Ошибка: красный `⚠` + «Не отправлено · Повторить» (кнопка).
- **Корзину рядом со временем удалить везде.**

### 3.3 Группировка

Подряд идущие сообщения одного автора в пределах 5 минут: отступ между ними 2 px (вместо 8–12), аватар (в группах) только у последнего, имя автора только у первого. Скругление «хвоста» — только у последнего в группе.

### 3.4 Опрос (Poll)

- Заголовок «ANONYMOUS POLL» оставить.
- Строка варианта: высота 48 px, текст **поверх** полосы, процент и число голосов справа, выбранный — галочка + акцентная граница.
- `role="radiogroup"`, варианты — `role="radio"` с `aria-checked`; стрелки ↑/↓ — навигация, `Space` — голос.
- «Retract vote» — текстовая кнопка 32 px высотой.
- Если опрос закрыт: варианты disabled, внизу «Poll closed · 7 votes», у победителя — акцентная метка.
- При голосовании: плавная анимация ширины полосы 300 мс (`transform: scaleX`, не `width`).

### 3.5 Геолокация

Вся карточка кликабельна (открывает карту/внешний сервис). Название — 15/600, адрес — 13 muted, иконка ↗ — подсказка. Hover: граница → акцентная, лёгкий подъём `translateY(-1px)`. Превью карты — ленивая загрузка с плейсхолдером той же высоты (избегаем layout shift).

### 3.6 Стикеры

Без бабла, без рамки. Клик — просмотр увеличенного/открыть набор. Hover — стандартная панель действий (3.1).

### 3.7 Реакции под сообщением

Ряд мини-пилюль «❤️ 2» (высота 24 px), своя реакция — акцентная граница; клик — добавить/снять. Максимум видимых 5, остальные «+3».

## 4. Вспомогательные элементы ленты (добавить)

1. **Кнопка «Вниз»** (FAB 40 px): появляется, если пользователь прокрутил вверх > 1 экрана. Справа внизу над полем ввода (отступ 16 px). Внутри — стрелка ↓ и бейдж с числом новых сообщений. Клик — плавный скролл (или мгновенный, если `prefers-reduced-motion`).
2. **Разделитель «New messages»** — горизонтальная линия с пилюлей по центру (акцент). Автоскролл к нему при открытии чата с непрочитанными.
3. **Индикатор «typing…»** — три точки в мини-бабле внизу ленты + текст в статусе шапки; пропадает через 5 с без события.
4. **Sticky-дата** (см. M9).
5. **Link-preview**: карточка под текстом со ссылкой (картинка 72 px, заголовок, домен). Закрываемая автором перед отправкой.
6. **Пустое состояние чата**: аватар 80 px, имя, «No messages yet — say hi 👋», кнопка-чипс «Say hello».

## 5. Smart-replies

- **Условие показа:** последнее сообщение входящее, ≤ 1 часа назад, и (содержит `?` либо это предложение/приглашение). Для исходящего последнего — **не показывать**.
- **Содержимое:** 3 варианта, контекстные, не обрезаются (без ellipsis, max 24 символа).
- **Позиция:** над полем ввода, отступ 8 px, горизонтальный ряд; слева метка «Smart» с иконкой AI.
- **Скрывать:** при начале ввода текста, при отправке сообщения, при клике ✕ (запоминать «скрыто для этого чата до следующего входящего» — не навсегда).
- **Клик по чипсу:** вставляет текст в поле и сразу отправляет (если включена настройка «отправлять сразу», по умолчанию — вставка в поле с фокусом, чтобы можно было отредактировать).
- **Анимация:** появление `opacity + translateY(4px)` 150 мс.
- **Доступность:** `role="group" aria-label="Quick replies"`, каждая — `button`.

### 6.1 Порядок элементов

```

```

| # | Элемент | Размер | Поведение |
|---|---------|--------|-----------|
| 1 | **Attach (＋ или 📎)** | 44 круг | Popover вверх: Фото/видео, Файл, Геолокация, Опрос, Контакт, Камера. Иконки 20 px + подпись. |
| 2 | **Поле ввода** | мин. высота 44, авторост до 6 строк (≈ 144 px), затем скролл | `Enter` — отправка, `Shift+Enter` — перенос (настройка). Placeholder контекстный. |
| 3 | **Emoji/Sticker/GIF** внутри поля справа | 32 | Открывает панель с вкладками; `Ctrl/⌘+;` — хоткей. |

### 6.2 Перенесённые функции (бывшие «часы» и «глаз»)

- **Долгое нажатие / ПКМ / стрелка ⌄ на кнопке Send** → меню **Send options**:
  - Send silently (без звука)
  - Schedule send… (бывшие «часы») → пресеты: Сегодня вечером, Завтра утром, Выбрать дату и время
  - *Пункт, соответствующий текущей функции «глаз»* — если это «исчезающее/одноразовое сообщение», назвать «Send as view-once»; если «режим приватности/скрыть превью» — перенести в «⋯ → Приватность». **Агенту: проверить в коде, что делает кнопка «глаз», и разместить пункт соответственно; иконку в основной строке не оставлять.**
- Пока есть отложенные сообщения в чате — в «⋯» появляется пункт «Scheduled (2)» и маленький индикатор 🕒 рядом с кнопкой Send.

### 6.3 Лента контекста над полем (Reply / Edit / Forward)

Высота 48 px, слева акцентная полоса 3 px, заголовок «Reply to Katie» / «Edit message» / «Forward 2 messages» (13/600), под ним превью 1 строка (13 muted), справа ✕. `Esc` — отмена. Для вложений — ряд превью 56×56 с ✕ на каждом и кнопкой «＋ ещё».

### 6.4 Запись голоса

Удержание 🎤: поле заменяется на `● 00:07  ←  Slide to cancel`, кнопка увеличивается ×1.3 с «дыханием». Свайп вверх — «залочить» запись (появляются ⏹, ▶ предпрослушивание, ➤ отправить, 🗑 отмена). Отпускание = отправка. Волна (waveform) в реальном времени. На desktop: клик — старт, клик — стоп, затем предпрослушивание.

### 6.5 Прочее

- **Форматирование:** `Ctrl/⌘+B / I / U / Shift+X` (зачёркнутый), `Ctrl+K` — ссылка. Мини-тулбар при выделении текста.
- **@Упоминания** (в группах): список участников над кареткой, навигация стрелками.
- **Slash-команды:** `/poll`, `/schedule`, `/location`.
- **Черновики:** автосохранение в `localStorage`/store по `chatId`, отображение «Draft: …» в списке чатов.
- **Drag & drop** файлов на всю область чата → оверлей «Drop files to send». Вставка картинок из буфера (`paste`).
- **Ограничение:** счётчик символов показывать только при приближении к лимиту (последние 10%).

## 8. Микровзаимодействия и анимации

Общее: `transition: 150–200 ms ease-out`; анимируем только `transform` и `opacity`. Уважать `@media (prefers-reduced-motion: reduce)` — отключать сдвиги/пружины, оставлять fade.

| Событие | Анимация |
|---------|----------|
| Появление нового сообщения | `opacity 0→1`, `translateY(8px→0)`, 180 мс; для своих — снизу справа |
| Отправка | Мгновенно показать с ⏱ (optimistic), затем статус по ответу сервера |
| Mic ↔ Send | Crossfade + scale 0.8→1, 150 мс |
| Hover-панель | `opacity` + `translateY(4px)`, 120 мс |
| Реакция | «Пружинка» scale 1→1.25→1, 250 мс |
| Переход к закрепу / результату поиска | Flash фона сообщения 1.2 с (акцент 15% → 0) |
| Пресс на кнопке | `scale(.96)` 80 мс |
| Focus-visible | Кольцо 2 px акцент + offset 2 px (только при клавиатурной навигации) |

## 10. Доступность (a11y)

- У каждой иконки-кнопки: `aria-label` и `title`/тултип; тогглы — `aria-pressed`; меню — `aria-haspopup="menu"`, `aria-expanded`.
- Лента: `role="log"` `aria-live="polite"` (новые сообщения озвучиваются, но не прерывают).
- Порядок Tab: шапка → лента (пропуск, переход стрелками) → smart-replies → поле ввода → кнопки поля.
- Контраст текста ≥ 4.5:1, иконок ≥ 3:1 (проверить muted-текст на тёмном фоне, время, подписи в табах).
- Не передавать смысл только цветом: статусы доставки дополнять формой (галочки), ошибки — иконкой + текстом.
- Все модальные окна/popover: ловушка фокуса, `Esc`, возврат фокуса на вызвавшую кнопку.
- Размеры хит-зон — см. принцип 6.

## 11. Оптимизация и производительность

1. **Виртуализация ленты** (`@tanstack/react-virtual` или `react-virtuoso`) — рендерить только видимые сообщения + буфер 10; сохранять позицию скролла при подгрузке истории вверх.
2. **Мемоизация**: `React.memo` для `MessageBubble`, `ChatListItem`; стабильные `key = message.id`; колбэки через `useCallback`; тяжёлые вычисления (группировка по дате/автору) — `useMemo`.
3. **Состояние**: селекторы (zustand/redux-toolkit `useSelector` с shallow) — компонент подписывается только на нужный срез; не держать весь список чатов в одном контексте.
4. **Optimistic UI** для отправки, реакций, голосования, закрепа; откат + тост при ошибке.
5. **Очередь оффлайн-отправки** (IndexedDB), автоповтор с экспоненциальной задержкой.
6. **Медиа**: резервировать размер по `width/height` (без прыжков вёрстки), blur-up превью, `loading="lazy"`, `decoding="async"`, превью-миниатюры для списка, оригинал — по клику.
7. **Тяжёлые панели — lazy-load** (`React.lazy` + `Suspense`): emoji/sticker/GIF-панель, галерея, карта, просмотрщик историй, запись голоса.
8. **Прочитанность** через `IntersectionObserver` (порог 0.6, батчинг запросов раз в 500 мс).
9. **Поиск**: debounce 150 мс, отмена предыдущего запроса (`AbortController`), локальный индекс последних сообщений.
10. **Эффекты**: `backdrop-filter` (стекло) не использовать на элементах внутри скролл-контейнера и в больших количествах; у фиксированных панелей — максимум на 2–3 элемента одновременно. Анимировать только `transform/opacity`; `will-change` — только на время анимации.
11. **Прыжки при подгрузке**: сохранять `scrollHeight` до/после prepend и корректировать `scrollTop`.
12. **Bundle**: проверить размер, tree-shaking иконок (импортировать по одной), шрифт — `font-display: swap`, subset.
13. **Метрики для проверки**: INP < 200 мс, отсутствие long tasks > 50 мс при скролле 1000 сообщений, CLS ≈ 0, 60 fps скролла на среднем ноутбуке.

## 16. Чего НЕ делать

- Не менять палитру, шрифт, радиусы, общий «стеклянный» стиль.
- Не добавлять новые видимые кнопки в шапку/поле без удаления равного количества старых.
- Не показывать подписи у иконок в шапке (только тултипы).
- Не выносить деструктивные действия на первый уровень.
- Не использовать анимации `width/height/top/left` — только `transform/opacity`.
- Не оставлять «глаз», «часы», «палитру» на видном месте без пояснения — они перенесены в меню (см. 2.2, 6.2).
