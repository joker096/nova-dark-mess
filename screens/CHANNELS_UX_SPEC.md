# CHANNELS_UX_SPEC.md — UX/UI-аудит и ТЗ на доработку раздела «Каналы»

> **Для ИИ-агента-исполнителя.** Продолжение `CHAT_UX_SPEC.md` (читать вместе с ним: общие принципы, `IconButton`, состояния кнопок, хоткеи, a11y и перформанс оттуда действуют и здесь).
> **Визуальный стиль не меняем**: тёмная тема, скругления, акцентный синий, карточки, шрифт, эмодзи-реакции. Только существующие токены.
> Меняем: состав и порядок кнопок, компактность шапки, календарь, карточку поста, левую панель, состояния и производительность.

Экран состоит из: **rail** (слева) → **ChannelList** (список каналов) → **ChannelView** (шапка с календарём + лента постов по дням).

## 2. Шапка канала — новая раскладка

### 2.1 Порядок элементов

```
[Avatar 40] [Название ✓ · 3.5M subscribers]                          [🔍 Search] [📅 Calendar] [🔔 Subscribed ▾] [⋯]
```

| # | Элемент | Размер | Действие |
|---|---------|--------|----------|
| 1 | Avatar | 40 | Открывает панель информации о канале |
| 2 | Название (16/600) + значок ✓ (если verified) | — | Клик — то же, что аватар |
| 3 | Подписчики (13 muted) | — | «3.5M subscribers · 4 posts today» |
| 4 | Search | 36 | Поиск по каналу |
| 5 | Calendar (toggle) | 36 | Показать/скрыть календарь (активное = акцентный фон 15%) |
| 6 | Subscribe / Subscribed | высота 36, pill | См. 2.2 |
| 7 | ⋯ More | 36 | См. 2.3 |

Удалить: «динамик», переключатель аватар-шеврон, «⌃».

**Адаптив:** < 1024 px — Search и Calendar остаются иконками, Subscribe → только иконка колокольчика; < 768 — в «⋯» уходят Search/Calendar, остаются Back, Avatar+имя, Subscribe-иконка, «⋯».

### 2.2 Кнопка Subscribe / Subscribed

| Состояние | Вид | Клик |
|-----------|-----|------|
| Не подписан | Primary pill «Subscribe» (акцентная заливка) | Подписаться (optimistic) → переход в «Subscribed» + тост «Subscribed · Undo» |
| Подписан, уведомления вкл. | Ghost pill `🔔 Subscribed ▾` | Меню: **Notifications: All posts / Highlights only / Muted** (с вариантами 1 ч, 8 ч, навсегда) · **Unsubscribe** (красный, последний) |
| Подписан, mute | Ghost pill `🔕 Muted ▾` | то же меню |

### 2.3 Меню «⋯» (порядок)

1. Share channel (копировать ссылку / отправить в чат / внешний share)
2. Channel info
3. Media & files
4. Saved posts
5. Search in channel *(если скрыт)*
6. — разделитель —
7. Report *(красный)*
8. Unsubscribe *(красный, если подписан)*

Для админов, перед разделителем: Edit channel, Statistics, Admins, Invite link, Scheduled posts.

### 2.4 Поиск по каналу

Поле разворачивается в шапке на место названия, `Esc` закрывает. Под ним полоса фильтров (чипсы): `All · Photos · Videos · Links · Files`, выбор диапазона дат (использует календарь). Результаты — та же лента, совпадения подсвечены; навигация `Enter` / `Shift+Enter`, счётчик «3 of 12».

## 3. Календарь

### 3.1 Раскладка

```
‹   November 2026 ⌄   [Today]   ›
SUN   MON   TUE   WED   THU   FRI   SAT
 8     9     10    11    12    13    14
 ·     ··    ···   ·     ·           ●
```

- Показывается **неделя** (7 ячеек), по умолчанию — неделя выбранного дня. Ячейка: ширина 1/7, высота 64 px, радиус как у текущих chip-ов, подпись дня недели 11/600 uppercase muted, число 16/600.
- Стрелки ‹ › — предыдущая/следующая неделя; `Today` — возврат к сегодня.
- Клик по «November 2026 ⌄» → popover с месячной сеткой (heat-карта активности: интенсивность точки по числу постов), навигация по месяцам/годам.
- Мобайл: свайп влево/вправо по полоске = неделя.

### 3.2 Состояния ячейки дня

| Состояние | Вид |
|-----------|-----|
| Обычный день с постами | Число normal, точки активности под числом |
| День без постов | Число muted (60%), без точек, кликабелен (ведёт к ближайшему посту, тост «No posts this day») |
| Будущий | opacity 35%, disabled, `aria-disabled="true"` |
| **Сегодня** | Контурная акцентная рамка 1.5 px |
| **Выбранный** | Залитый фон (акцент 20%) + рамка акцент |
| Сегодня + выбранный | Заливка + рамка + маленькая метка «•» под числом |
| Есть непрочитанные | Синяя точка 6 px над/под числом (отдельно от точек активности) |
| Hover | Фон +6% |
| Focus-visible | Кольцо 2 px |

Индикатор активности: 1 пост → 1 точка, 2–4 → 2, 5+ → 3. Цвет точек — muted, у непрочитанных — акцент.

### 3.3 Поведение (scrollspy)

- Клик по дню → плавный скролл ленты к заголовку этого дня (если день ещё не загружен — загрузить и затем доскроллить).
- При скролле ленты выделенный день в календаре обновляется автоматически (по заголовку дня, который находится у верхней границы). Обновлять не чаще чем раз в 100 мс (rAF + IntersectionObserver).
- Если выбранный день ≠ сегодня и вы ушли от последних постов — `Today` становится акцентной pill-кнопкой.
- Клавиатура (фокус в календаре): `←/→` день, `↑/↓` неделя, `PageUp/PageDown` месяц, `Home/End` начало/конец недели, `Enter` выбрать, `T` — сегодня.

### 3.4 Сворачивание

Календарь по умолчанию раскрыт на десктопе, свёрнут на мобайле. При скролле вниз > 1 экрана авто-сворачивается в одну строку: `Nov 10 · 4 posts ⌄` (клик раскрывает). Состояние `calendarOpen` хранится в `localStorage` per-user. Сворачивание — через `grid-template-rows: 1fr → 0fr` + `opacity` (допустимое исключение из правила «только transform/opacity»), 200 мс.

## 4. Лента и пост

### 4.1 Лента

- Колонка ленты: `max-width: 840px`, по центру области (на широких экранах); поля 16–24 px.
- **Sticky-заголовок дня**: `TUESDAY, NOVEMBER 10 · 4 posts`; для текущего/вчерашнего — «TODAY» / «YESTERDAY». Прилипает под шапкой (`top: header+calendar`).
- Бесконечная подгрузка в обе стороны (по дням, cursor-pagination).
- Разделитель **New posts** (акцентная линия + пилюля) на границе прочитанного; открытие канала скроллит к нему.
- FAB **«Jump to latest»** (40 px, справа снизу) со счётчиком новых постов; появляется, когда пользователь ушёл вверх > 1 экрана.
- Live-обновление: новые посты при открытом канале не «выталкивают» пользователя — показать пилюлю «↑ 3 new posts» вверху ленты.

### 4.2 Анатомия поста

```
10:30 │ ┌──────────────────────────────────────────────────┐
      │ │ 📌 Pinned · edited                          ⋮    │
      │ │ **Заголовок**                                    │
      │ │ Текст… Read more                                 │
      │ │ [медиа]                                          │
      │ │ ❤️ 36  😱 28  😡 4  🥶 10  ➕       💬 44  👁 12.4K  ↗ │
      │ └──────────────────────────────────────────────────┘
```

Футер — два блока:
- **Слева — реакции:** pill-ы высотой 28 px (эмодзи 16 + число 13/600), максимум 4–5 видимых + «+N», затем «➕» (добавить реакцию → мини-палитра). Своя реакция — акцентная граница/заливка 15%. Сортировка по убыванию счёта.
- **Справа — взаимодействия:** `💬 44` (кнопка; на ≥ 1280 px с подписью «44 comments»), `👁 12.4K` (muted, не кнопка), `↗` (share).

Числа форматировать: 1 234 → 1.2K, 3 500 000 → 3.5M. Реакции — optimistic: клик мгновенно +1/−1, анимация «пружинка» (scale 1→1.25→1, 250 мс), откат при ошибке.

Верхняя строка поста (мелкая, muted, показывать только если есть что показать): `📌 Pinned`, `Forwarded from …`, `edited`.

### 4.3 Медиа

| Тип | Правило |
|-----|---------|
| Одно фото | `aspect-ratio` из метаданных, `max-height: min(560px, 70vh)`, `object-fit: cover`, радиус как у карточки, blur-up плейсхолдер |
| 2 фото | 2 колонки, одинаковая высота |
| 3 фото | 1 большое слева + 2 маленьких справа |
| 4 фото | сетка 2×2 |
| 5+ | сетка 2×2, на последней плитке оверлей «+N» |
| Видео | постер + кнопка ▶ по центру + длительность в углу; без автозвука; GIF/короткие клипы — autoplay muted loop при видимости ≥ 50% |
| Подпись | под медиа, внутри карточки, `line-clamp: 6` |

**Lightbox:** клик по медиа → полноэкранный просмотр: затемнение, ← → (и свайп), `Esc`, zoom (колесо/pinch/двойной клик), счётчик «2 / 5», кнопки ⬇ Download и ↗ Share, миниатюры снизу при альбоме. Фокус возвращается на плитку при закрытии.

### 4.4 Меню поста «⋯»

Показывать при hover/focus карточки (на touch — всегда).

1. Copy link
2. Share
3. Save / Unsave
4. Copy text
5. Translate
6. Report *(красный)*
7. *(админ, отдельным блоком под разделителем)*: Edit · Pin/Unpin · View statistics · **Delete** *(красный, последний, с подтверждением)*

## 5. Комментарии

- Клик по `💬 44` → **правая панель** шириной 420 px (десктоп; ленту сдвигает или перекрывает с затемнением на < 1280 px), на мобайле — полноэкранный экран/шторка на 90% высоты.
- Структура: шапка «44 comments» + сортировка (Top / Newest) + ✕; свёрнутая цитата поста (2 строки); список комментариев (аватар, имя, время, текст, ♥, Reply; ответы — 1 уровень вложенности, «Show 5 replies»); нижний composer (аналог composer из `CHAT_UX_SPEC.md` §6: `[+] [поле] [😊] [➤]`).
- Deep link: `?post=ID&comments=1`; `Esc` закрывает; состояние панели сохраняется при смене календарной даты.
- Если комментарии отключены — кнопка `💬` скрыта.

| Гость (не подписан) | Нижняя панель 56 px: широкая primary-кнопка «Subscribe» + число подписчиков |
| Подписчик | Ничего (максимум пространства ленте); уведомления — через кнопку в шапке |
| Админ | Composer публикации: `[＋ вложение] [поле «Write a post…»] [🕒 Schedule] [➤ Publish]`; черновики; предпросмотр |

### 6.2 Пустые и служебные состояния

- **Пустой день:** по центру «No posts on Tuesday, Nov 10» + кнопки «Previous post day» / «Latest».
- **Нет подписок:** иконка канала + «Find channels you like» + чипсы категорий + блок Recommended.
- **Загрузка:** скелетоны постов (заголовок + 2 строки + плитка медиа), shimmer 1.4 с.
- **Ошибка загрузки:** карточка «Couldn't load posts · Retry».
- **Оффлайн:** полоса «Offline» под шапкой, лента из кэша.
- **Канал удалён/приватный:** отдельный экран с причиной.

### 6.3 Панель информации о канале

Правая панель/шторка: аватар 96, название ✓, описание, ссылка (copy), подписчики, переключатель уведомлений, вкладки Media / Files / Links, «Similar channels», Report; для админа — Edit, Stats, Admins, Invite link.

## 8. Доступность

- Календарь: `role="grid"`; ячейка — `role="gridcell"` с `aria-label="Tuesday 10 November, 4 posts, selected"`, `aria-current="date"` у сегодняшней, `aria-selected`, `aria-disabled` у будущих.
- Пост — `<article aria-labelledby>`; реакции — кнопки с `aria-pressed` и `aria-label="Love, 36 reactions, you reacted"`.
- Кнопка Subscribe — `aria-haspopup="menu"`, текстовое состояние (не только цвет/иконка).
- Новые посты — `aria-live="polite"` пилюля «3 new posts».
- Lightbox: ловушка фокуса, `aria-modal`, `Esc`, возврат фокуса; у изображений `alt` (из подписи или «Photo from {channel}»).
- Контраст muted-текста (время, подписи дней недели, «posts») ≥ 4.5:1; не передавать смысл только цветом (выбранный/сегодня различаются заливкой и рамкой).
- `prefers-reduced-motion`: без пружин и скролл-анимаций, fade only.

## 9. Оптимизация и производительность

1. **Данные календаря:** один запрос на месяц возвращает `{ "2026-11-10": { posts: 4, unread: 2 }, … }`; префетч соседних месяцев; кэш (React Query / RTK Query), `staleTime` 60 с.
2. **Лента:** виртуализация (`@tanstack/react-virtual`) по группам «день → посты», динамическая высота, cursor-пагинация по дням, сохранение scroll-позиции при подгрузке вверх (компенсация `scrollTop`).
3. **Медиа:** `srcset` (480/960/1600), WebP/AVIF, `loading="lazy"`, `decoding="async"`, размеры из метаданных (нулевой CLS), blur-up (LQIP 20–30 px), preload только первого видимого изображения; видео — `preload="metadata"`.
4. **Реакции/просмотры:** нормализованное хранилище постов (изменение реакции не перерисовывает всю ленту); optimistic update + дебаунс/батч запросов; real-time счётчики по WebSocket с throttle 1/сек и обновлением только видимых постов.
5. **Просмотры:** засчитывать через `IntersectionObserver` (≥ 50% поста на экране ≥ 1 с), один раз за сессию, отправка батчем раз в 5 с.
6. **Мемоизация:** `React.memo` для `PostCard`, `ReactionPill`, `CalendarDay`; стабильные `key`; `useCallback` для хендлеров.
7. **Lazy-load:** lightbox, emoji/реакционная палитра, панель комментариев, мастер создания канала, popover календаря-месяца (`React.lazy` + `Suspense`).
8. **Scrollspy:** один `IntersectionObserver` на заголовки дней, без `onScroll`-слушателей с чтением layout.
9. **Эффекты:** `backdrop-filter` не на элементах внутри скролла; анимации только `transform/opacity` (кроме сворачивания календаря, см. 3.4).
10. **Метрики:** LCP < 2.5 с на экране канала, INP < 200 мс, CLS ≈ 0, 60 fps при скролле 500+ постов.

## 11. Критерии приёмки

- [ ] Шапка + календарь ≤ 160 px высоты, нет пустых зон внутри карточки шапки.
- [ ] В шапке нет кнопки «динамик» и переключателя аватар-шеврон; есть явная Subscribe/Subscribed с текстом.
- [ ] Календарь показывает 7 дней, не обрезается; будущие даты disabled; «сегодня» и «выбранный» визуально различимы; Today подсвечивается при уходе от сегодняшнего дня.
- [ ] Клик по дню скроллит к дню; при скролле календарь обновляется.
- [ ] Медиа ограничено по ширине и высоте; клик открывает lightbox; нет CLS при загрузке.
- [ ] Реакции и комментарии визуально разделены; есть просмотры, share; меню поста содержит Copy link/Share/Save/Report.
- [ ] Комментарии открываются в боковой панели, deep link работает.
- [ ] Плавающей кнопки share внизу слева нет; нижняя область зависит от роли.
- [ ] В списке секции Following / Recommended; бейджи — числа непрочитанных; таб «Channels» убран из фильтров чатов.
- [ ] Все иконки-кнопки имеют `aria-label`, тултип и focus-ring; календарь управляется клавиатурой.
- [ ] Лента с 500+ постов скроллится плавно; метрики из раздела 9 выполнены.

## 12. Чего НЕ делать

- Не менять палитру, шрифт, радиусы, стиль карточек и реакций.
- Не возвращать «динамик» и аватар-шеврон в шапку; не добавлять новых видимых кнопок без удаления равного числа старых.
- Не растягивать медиа на всю ширину экрана.
- Не смешивать комментарии и реакции в одном ряду.
- Не делать календарь с обрезанными днями — только недельный вид со scroll/swipe.
- Не засчитывать просмотр при простом рендере поста вне видимой области.
