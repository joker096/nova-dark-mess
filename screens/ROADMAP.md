# ROADMAP.md — дорожная карта UX-доработок мессенджера (v2)

> **Для ИИ-агента-исполнителя.** Единый план внедрения для двух документов:
> - `CHAT_UX_SPEC.md` — экран чата и список чатов (ID: H*, M*, C*, L*)
> - `CHANNELS_UX_SPEC.md` — раздел «Каналы» (ID: CH-H*, CH-C*, CH-F*, CH-L*, CH-B*)
>
> Эта версия **заменяет** раздел 14 из `CHAT_UX_SPEC.md`.
> Правило: этап закрывается только когда выполнены его пункты Definition of Done. Визуальный стиль не менять, только существующие токены.

**Что изменилось по сравнению с v1:** добавлен раздел «Каналы»; выделен этап 0 с общими компонентами (чтобы чат и каналы не делали одно и то же дважды); принято решение по дублю «Channels» (см. §5); этапы пересобраны по зависимостям.

Оценки в рабочих днях для одного агента/разработчика, ориентировочные.

## 5. Принятые решения (журнал)

| Вопрос | Решение | Почему |
|--------|---------|--------|
| Дубль «Channels»: rail-иконка и таб в списке чатов | Rail остаётся, **таб «Channels» убираем** из фильтров чатов; каналы остаются в «All» | Каналы — отдельный раздел со своим интерфейсом (календарь, лента); таб создавал путаницу |
| Календарь канала | Недельный вид + месячный popover, scrollspy | Месячная строка обрезалась и не масштабировалась |
| Кнопка «динамик» | Заменена на Subscribe/Subscribed | Неясный смысл у самой яркой кнопки |
| Кнопка «share» внизу слева | Удалена, share в «⋯» и в футере поста | Неясный объект действия |
| Реакции vs комментарии | Разнесены по сторонам футера | Разные по смыслу действия |
| Компактные сторис vs вход через поиск (в стиле Telegram Desktop) | По умолчанию компактный ряд 72 px; финальный выбор за владельцем | Не блокирует остальное |

## 6. Открытые вопросы (агенту проверить в коде или уточнить)

1. Что делает кнопка «глаз» в поле ввода чата → куда её переносить (см. CHAT §6.2).
2. Есть ли в продукте роль админа канала (нужен ли Admin composer и статистика на этапе 2) — если нет, 2.12 ограничить ролями гость/подписчик.
3. Можно ли показывать список подписчиков канала (CH-H7).
4. Включены ли комментарии в каналах по умолчанию (определяет видимость 💬).
5. Нужен ли перевод постов (пункт Translate в меню поста) на этапе 2 или позже.

## 7. Риски

| Риск | Митигация |
|------|-----------|
| Рефакторинг шапок ломает адаптив | Сначала сделать брейкпоинты из CHAT §2.1 и CH §2.1, тест на 4 ширинах: 1440 / 1024 / 768 / 390 |
| Scrollspy + бесконечная подгрузка дают прыжки скролла | Компенсация `scrollTop` при prepend, тесты на подгрузке вверх |
| Слишком много `backdrop-filter` на слабых устройствах | Ограничить 2–3 элементами, fallback без blur по media query |
| Расхождение стилей между чатом и каналами | Только общие компоненты из этапа 0, ревью на использование `IconButton`/`Menu` |

## 8. Метрики успеха

- Меньше кликов до основных действий: подписка — 1 клик, ответ на сообщение — 1 действие, переход к нужному дню канала — 1 клик.
- Количество видимых иконок в шапках: чат ≤ 6, канал ≤ 5 (на ≥ 1280 px).
- Технические: LCP < 2.5 с, INP < 200 мс, CLS ≈ 0, 60 fps скролла.
- Качество: 0 критичных замечаний axe, 100% иконок-кнопок с `aria-label`.
