Установка виджета чата

Бесплатный виджет чата Mess&Anger для вашего сайта. Посетители пишут вам без регистрации, вы отвечаете из приложения.

Шаг 1. Получите Site ID

В приложении Mess&Anger перейдите в экран «Сайты», нажмите «Подключить сайт», укажите название и домены, затем скопируйте готовый сниппет с кнопкой «Копировать».

<script async src="https://mess.cvr.name/widget/loader.js" data-site="YOUR_SITE_ID"></script>

Шаг 2. Вставьте сниппет на вашу платформу

Обычный HTML

Вставьте скрипт перед закрывающим тегом </body> на каждой странице, где нужен чат:

<script async src="https://mess.cvr.name/widget/loader.js" data-site="YOUR_SITE_ID"></script>

Tilda

В редакторе сайта перейдите в «Настройки сайта» → «HTML и код» → «В» или «Перед тегом </body>» и вставьте:

<script async src="https://mess.cvr.name/widget/loader.js" data-site="YOUR_SITE_ID"></script>

Wix

В редакторе сайта перейдите в «Настройки» → «Пользовательские коды» → «Добавить пользовательский код». Вставьте код, выберите placement «Тело - конец» и страницы «Все страницы»:

<script async src="https://mess.cvr.name/widget/loader.js" data-site="YOUR_SITE_ID"></script>

Shopify

В админке перейдите в «Интернет-магазин» → «Темы» → «Действия» → «Редактировать код». Откройте файл theme.liquid и вставьте перед </body>:

<script async src="https://mess.cvr.name/widget/loader.js" data-site="YOUR_SITE_ID"></script>

Joomla

Используйте расширение для вставки кода (например, «Custom HTML» или «Sourcerer») или отредактируйте шаблон, вставив код перед </body> в index.php вашего шаблона:

<script async src="https://mess.cvr.name/widget/loader.js" data-site="YOUR_SITE_ID"></script>

WordPress

Установите плагин Mess Chat из каталога WordPress.org или загрузите вручную. В настройках плагина укажите Site ID и включите виджет.

Или вставьте код вручную через «Внешний вид» → «Редактор тем» → файл footer.php перед </body>:

<script async src="https://mess.cvr.name/widget/loader.js" data-site="YOUR_SITE_ID"></script>

Шаг 3. Проверьте установку

Откройте свой сайт в браузере. Кнопка чата должна появиться в правом (или левом) нижнем углу. Нажмите на неё — откроется окно чата. Напишите тестовое сообщение и убедитесь, что оно пришло в приложение Mess&Anger.

Приватность: виджет не использует трекеры, внешние шрифты и сторонние скрипты. Все сообщения шифруются сквозным шифрованием. Сервер видит только зашифрованный текст и метаданные (время, размер, ID чата).
