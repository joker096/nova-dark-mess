Embed the free Mess&Anger chat widget on your WordPress site. Visitors can message you without registration; you reply from the Mess&Anger app.

== Description ===

Mess Chat adds a lightweight, privacy-focused live-chat widget to your WordPress site. It connects to the Mess&Anger messenger so you can reply to website visitors directly from the app.

Features:
* Free live chat widget for any WordPress site
* Visitors write without registration
* End-to-end encrypted messages
* Connect via the Mess&Anger app (no manual copying)
* Customizable language and position
* Optional first-party mode to bypass ad blockers
* GDPR-friendly: no trackers, no external fonts, no third-party scripts

== Installation ===

1. Upload the `mess-chat` folder to `/wp-content/plugins/`.
2. Activate the plugin through the 'Plugins' menu in WordPress.
3. Go to Settings → Mess Chat.
4. Click "Подключить через Mess&Anger" to link your site, or paste your Site ID manually.
5. Enable the widget and save.

== Frequently Asked Questions ===

= Do visitors need to install the app? =
No. Visitors can chat directly from your website without installing anything.

= Is the chat encrypted? =
Yes. Messages are end-to-end encrypted between the visitor and the site owner.

= What is first-party mode? =
It serves the widget loader from your own domain, which helps avoid ad-blocker filters. Requires server configuration.
